📅 Google Calendar MCP Server

Welcome to the authenticated Google Calendar Model Context Protocol (MCP) server powered by AgentHost.

Getting Started

  1. Step 1: Log In with Google
  2. Step 2: Grant Google Calendar permissions at /authorize/google
  3. Step 3: Check your session & token status at /status

MCP Client Configuration

Connect Claude Desktop, Cursor, or your AI assistant to this MCP server:

{
  "mcpServers": {
    "google-calendar": {
      "url": "{{.BaseURL}}/mcp",
      "headers": {
        "Authorization": "Bearer <your-session-id>"
      }
    }
  }
}

Available Tools:

  • read_calendar: Retrieve meetings and events for a date or today.
  • get_user_info: View current authenticated identity and permissions.
